# Day 4｜本地靶场复现：SQL 注入、XSS、文件上传

一句话结论：复现不是为了展示攻击技巧，而是为了理解检测告警、日志证据和修复方法。

> 所有实验只在本地 DVWA 或明确授权的隔离环境中进行。

## 1. 启动 DVWA

```bash
docker compose -f lab/docker-compose.yml up -d
```

浏览器打开：

```text
http://localhost:8080
```

首次登录后进入 `DVWA Security`，把安全等级调为 `low`。

## 2. SQL 注入

位置：`SQL Injection`

输入：

```sql
1' OR '1'='1
```

观察：页面返回多条用户记录，说明输入进入了 SQL 查询。

防护：参数化查询、最小权限、WAF 规则和错误信息收敛。

## 3. 反射型 XSS

位置：`XSS (Reflected)`

输入：

```html
<script>alert('xss')</script>
```

观察：浏览器执行了输入内容。

防护：输出编码、CSP、输入白名单。

## 4. 文件上传

位置：`File Upload`

先上传普通文本文件，再把扩展名或 MIME 类型改为允许的图片类型，观察服务器校验是否只信任前端声明。

防护：

- 服务端校验扩展名、MIME 和内容；
- 上传目录禁止执行；
- 文件名随机化；
- 隔离存储。

## 5. 我踩过的坑

- DVWA 初始安全等级不是 low；
- 容器启动后数据库需要初始化；
- 浏览器缓存导致 payload 结果没有刷新；
- 只看前端校验，误以为上传接口安全。

## 6. 与告警分诊 POC 的关系

这三类实验分别对应 WAF、应用日志和 EDR 可能产生的告警，为 Day 5 的情报富化和风险评分提供场景。
