# Day 7｜售前视角：把安全技术讲成业务价值

一句话结论：客户购买的不是检测规则数量，而是更低的误报、更快的响应、更完整的证据和更可控的风险。

## 1. 同一件事的三种讲法

| 对象 | 关注点 | 表达方式 |
|---|---|---|
| 工程师 | 数据源、规则、接口 | 说明数据流和可扩展性 |
| IT 主管 | 人力、流程、稳定性 | 说明降噪、处置效率 |
| 业务负责人 | 风险、合规、损失 | 说明业务影响和证据链 |

## 2. 价值量化四件套

1. 误报降噪；
2. 响应时间；
3. 人力节省；
4. 合规与审计证据。

## 3. 一页解决方案模板

```text
客户问题
  -> 现状与风险
  -> 方案架构
  -> POC 范围
  -> 验收指标
  -> 实施计划
  -> 成本和收益
  -> 下一步
```

## 4. 用告警分诊 POC 做示范

240 条脱敏告警对照测试中：

- 高危误报从 120 条降至 60 条；
- 高危精确率从 33.3% 提升至 50%；
- 在 180 秒人工基线和 60 秒人工确认假设下，预估 MTTI 降低约 66.7%。
